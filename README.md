# Jossef Daysor — Portfolio Website

A responsive personal portfolio built with plain HTML and CSS. It is ready to publish with GitHub Pages.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling and visual design

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `jossef-portfolio`).
2. Upload `index.html` and `style.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.
